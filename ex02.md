Q5. Classement

Absolus (commencent par /) : /etc/passwd, /
Relatifs : ../alice, ./script.sh, cours/linux.txt, ..

Q6. Pourquoi ./script.sh ?
Pour une commande sans /, le shell cherche uniquement dans les répertoires listés dans la variable PATH. Le répertoire courant n’y figure pas, par sécurité : sinon un fichier piégé placé dans un dossier pourrait s’exécuter à ton insu. Avec ./, tu donnes un chemin explicite et le shell n’a plus besoin de consulter le PATH.
