# Exercice 2 : Chemins absolus et relatifs

## Étape 1 : Q1 à Q3 — Les chemins

### Q1. Chemin absolu de `linux.txt`

Un chemin absolu part de `/`. On descend : `home` → `groupeA` → `alice` → `cours`.

```text
/home/groupeA/alice/cours/linux.txt
```

### Q2. Depuis `/home/groupeA/bob` vers `linux.txt`

`..` remonte dans `groupeA`, puis on redescend dans `alice/cours`.

```text
../alice/cours/linux.txt
```

### Q3. Depuis `/home/groupeB/carla/projets/tp1` vers `notes`

Il faut remonter jusqu’à `home` :

- `..` = projets
- `../..` = carla
- `../../..` = groupeB
- `../../../..` = home

Puis on redescend vers `groupeA/bob/notes`.

```text
../../../../groupeA/bob/notes
```

## Étape 2 : Q4 — La séquence de `pwd`

### a. Première séquence

| Commande | Où on est |
|---|---|
| `cd /home/groupeA/alice` | `/home/groupeA/alice` |
| `cd cours` | `/home/groupeA/alice/cours` |
| `cd ../../bob` | `/home/groupeA/bob` |

Explication : on remonte de deux niveaux jusqu’à `groupeA`, puis on descend dans `bob`.

### b. Deuxième séquence

```bash
cd ../../groupeB/./carla/projets/..
pwd
```

Depuis `bob`, `../..` mène à `/home`. Le `.` ne change rien. On descend dans `groupeB/carla/projets`, puis le dernier `..` remonte d’un niveau.

Résultat :

```text
/home/groupeB/carla
```

### c. Troisième séquence

```bash
cd /
cd ..
pwd
```

La racine n’a pas de parent. `..` reste donc à la racine.

Résultat :

```text
/
```

### d. Quatrième séquence

```bash
cd
pwd
```

La commande `cd` seule ramène au répertoire de connexion.

Résultat :

```text
/home/groupeA/alice
```

## Étape 3 : Q5 et Q6

### Q5. Classement des chemins

**Chemins absolus** (commencent par `/`) :

- `/etc/passwd`
- `/`

**Chemins relatifs** :

- `../alice`
- `./script.sh`
- `cours/linux.txt`
- `..`

### Q6. Pourquoi utiliser `./script.sh` ?

Pour une commande sans `/`, le shell cherche uniquement dans les répertoires listés dans la variable `PATH`.

Le répertoire courant n’y figure généralement pas, par sécurité : sinon, un fichier piégé placé dans un dossier pourrait s’exécuter à ton insu.

Avec `./`, tu donnes un chemin explicite et le shell n’a plus besoin de consulter le `PATH`.

## Étape 4 : Q7 — Recréer l’arborescence dans Linux

### 1. Commandes exécutées

```bash
mkdir -p ~/arbo/home/groupeA/alice/cours ~/arbo/home/groupeA/bob/notes ~/arbo/home/groupeB/carla/projets/tp1
```

```bash
touch ~/arbo/home/groupeA/alice/cours/linux.txt ~/arbo/home/groupeA/alice/monfichier
```

### 2. Vérification de l’arborescence

Commande :

```bash
find ~/arbo
```

Résultat obtenu :

```text
/home/baba-niang/arbo
/home/baba-niang/arbo/home
/home/baba-niang/arbo/home/groupeA
/home/baba-niang/arbo/home/groupeA/bob
/home/baba-niang/arbo/home/groupeA/bob/notes
/home/baba-niang/arbo/home/groupeA/alice
/home/baba-niang/arbo/home/groupeA/alice/cours
/home/baba-niang/arbo/home/groupeA/alice/cours/linux.txt
/home/baba-niang/arbo/home/groupeA/alice/monfichier
/home/baba-niang/arbo/home/groupeB
/home/baba-niang/arbo/home/groupeB/carla
/home/baba-niang/arbo/home/groupeB/carla/projets
/home/baba-niang/arbo/home/groupeB/carla/projets/tp1
```

### 3. Vérification du chemin relatif vers `linux.txt`

Commandes exécutées :

```bash
cd ~/arbo/home/groupeA/bob
ls ../alice/cours/linux.txt
```

Résultat obtenu :

```text
../alice/cours/linux.txt
```

### 4. Vérification du chemin relatif vers `notes`

Commandes exécutées :

```bash
cd ~/arbo/home/groupeB/carla/projets/tp1
ls -d ../../../../groupeA/bob/notes
```

Résultat obtenu :

```text
../../../../groupeA/bob/notes
```

### 5. Vérification de la séquence de commandes

Commandes exécutées :

```bash
cd ~/arbo/home/groupeA/alice
cd cours
cd ../../bob
pwd
cd ../../groupeB/./carla/projets/..
pwd
cd /
cd ..
pwd
cd
pwd
```

Résultats obtenus :

```text
/home/baba-niang/arbo/home/groupeA/bob
/home/baba-niang/arbo/home/groupeB/carla
/
/home/baba-niang
```
